# VLM 관계 해석 불확실성 — 2026-09-08 17:47 KST

- 증상: 이미지 QA 연결 실측에서 모델이 연결 부재를 단정하거나 원본에 확인되지 않는 화살표를 설명했다. 동시에 uncertainties에는 관계 불명확을 적었다.
- 원인: 픽셀 입력·JSON 계약 성공은 시각 해석의 사실 정확성을 보장하지 않는다. 프롬프트 보완만으로 오류가 해결되지 않았다.

- 검증: 모순된 확신/불확실성 응답의 기권 회귀를 추가했다. 실제 두 관계 응답은 품질 미통과로 기록하며 전체 VLM 정확도 개선을 주장하지 않는다.
- 재발 방지: 원본 위치 무결성, 이미지 입력 성공, 생성 출력 계약, 내용 품질을 별도 판정한다. 자기보고 불확실성은 보류 신호이며 정확도 점수가 아니다.
