# External Data Egress Decision Record

상태: PENDING_EGRESS_APPROVAL  
날짜: 2026-08-24

## 질문

비밀유지 대상 RFP를 외부 실행 환경으로 보낼 수 있는 범위는 어디까지인가?

## 근거

- 과제 가이드는 해당 corpus로 OpenAI API 시나리오와 팀 전용 GCP 시나리오를 모두 구현하도록 요구한다.
- 동시에 원본 RFP를 외부에 공유하거나 GitHub·포트폴리오에 올리는 것을 금지한다.

## 현재 결정

- 과제가 두 시나리오를 요구한다는 사실만으로 이 특정 Drive 복사본의 외부 전송 권한이 자동 확정되지는 않는다.
- 운영진 또는 데이터 소유자의 처리 지침, 계정별 보존·학습 설정과 PII 전송 범위를 확인하기 전에는 로컬 처리만 허용한다.
- 일반 SaaS, 임의 Vector DB API, 개인 클라우드와 다른 생성형 AI 서비스에는 전송하지 않는다.
- Batch 0~2는 로컬 schema·계약·표본 파서 검증만 수행하고 외부 모델 호출은 하지 않는다.
- 공개 금지는 전송 승인과 별개다. 처리 승인을 받아도 원본·추출문·청크·private gold는 공개하지 않는다.

## 재검토 조건

- 운영진 또는 데이터 소유자의 별도 데이터 처리 지침이 확인되는 경우
- 제공된 계정이 아닌 외부 서비스 사용이 필요해지는 경우
- 원문 보존·학습 사용 정책을 확인할 수 없는 모델 공급자를 검토하는 경우
