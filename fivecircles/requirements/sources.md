## 2. 실제 corpus

- URL: Git 밖 `private/deferred-references.md`에 보관
- 역할: 이 프로젝트에서 사용하는 유일한 RFP corpus
- 구성: `data_list.csv` 1개와 `files/` 아래 원문 100개
- 원문: HWP 96개, PDF 4개, 약 162.9 MiB
- CSV: 100행×12열, 파일명 정규화 후 원문과 100/100 대응
- 공유 가시성: connector metadata만으로 공개 여부를 검증할 수 없어 restricted로 취급

## 3. 확인된 데이터 품질 특성

- CSV `텍스트` 길이는 약 89~18,335자이고 문장·단어 중간에서 끝나는 사례가 있어 전체 본문이 아니다.
- PDF 원문은 약 46k~200k자까지 추출되지만 CSV에는 약 220~2,716자만 포함된 사례가 있다.
- HWP는 Drive connector가 본문을 직접 추출하지 못해 별도 HWP5 파서 또는 승인된 변환 경로가 필요하다.
- 결측: 공고번호 18건, 공고차수 18건, 입찰 시작일 26건, 마감일 8건.
- 금액: 결측 1건, 0원 6건, 1원 1건으로 총 8건이 결측·sentinel 의심값이다.
- 담당자 이름, 전화번호와 이메일이 원문에 포함될 수 있다.
- Drive 생성일은 복사 시각일 수 있으므로 시계열에는 CSV `공개 일자`를 사용한다.

## 4. 파일 조인 규칙

1. 파일명 앞의 `Copy of `를 한 번 제거한다.
2. 파일명 전체를 Unicode NFC로 정규화한다.
3. 확장자와 CSV 파일명 열을 명시적으로 대조한다.
4. 중복·미매칭·다중매칭을 오류로 기록하고 추측으로 연결하지 않는다.

## 5. 사용 경계

- CSV metadata와 `사업 요약`: 문서 라우팅·필터·표시용
- HWP/PDF 원문 추출 결과: 검색·인용 근거용
- 원본·추출문·청크·private 평가 근거: restricted, Git 금지
- 코드·스키마·집계 지표·비식별 예시: 공개 가능
