# Blogger HTML QA Checklist

- Paste into Blogger's HTML view, not the normal compose editor.
- Confirm the post width stays inside the theme column.
- Confirm code blocks wrap or scroll horizontally instead of stretching the page.
- Confirm tables are inside a visible scroll wrapper.
- Replace every `.image-slot` with an uploaded Blogger image.
- After inserting images, set image size/alignment in Blogger if needed.
- Preview the post on desktop and mobile before publishing.
