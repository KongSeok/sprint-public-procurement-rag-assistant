# Agent Scoring

This skill evaluates and records work performance quantitatively.

## When to Use

- After completing tasks (part of ultra-record)
- When the user requests scoring evaluation
- For performance tracking

## Scoring Process

1. Read `fivecircles/scoring/agent-scoring-policy.md`
2. Evaluate completed work against policy criteria
3. Calculate points (gains/losses/bonuses)
4. Record in `fivecircles/scoring/log-score.md`
5. Update optimization suggestions

See the full protocol in `../protocol_agent_scoring.md`.
