# Logging & Summary

This skill standardizes all project documentation after work completion.

## When to Use

- After completing a task or feature
- When the user says "로그 요약해" or "logging summary"
- Before committing changes

## What It Logs

1. **update.md**: Work progress and changes
2. **todolist.md**: Task status updates
3. **sync.md**: Team synchronization notes
4. **errorlogs/**: Error documentation
5. **debate.md**: Decision records

See the full protocol in `../protocol_logging_summary.md`.
