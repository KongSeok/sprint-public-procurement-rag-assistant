# VLM + v3.0.1 + 인용 형식 통일 실험

## 1. 실험 개요

이번 실험은 최신 텍스트 생성 파이프라인에 기존 Qwen3-VL 시각 판독 결과를 연결하고, 채점기 v3.0.1과 통일된 인용 형식을 적용한 통합 평가다.

다만 아래 결과는 현재 실행에 사용된 골든셋과 채점기의 산출값이다. 검수 과정에서 `supplemental-set-b15`의 정답 문서 3개 누락과 `supplemental-qa-g22`의 기권 오분류가 확인됐으므로 **85.37점은 수정 전 잠정 점수**로 관리한다.

### 변화량

최신 텍스트 실험 대비:

- End-to-End: `82.33 → 85.37` (**+3.04%p**)
- 어휘 사실 점수: `82.32 → 87.63` (**+5.31%p**)

기존 v3.0.1 결과 대비:

- End-to-End: `70.12 → 85.37` (**+15.25%p**)
- 어휘 사실 점수: `74.24 → 87.63` (**+13.39%p**)

초기 채점기 v3.0.0의 74.67점은 형태소 일부 일치로 인한 과대 채점이 확인됐으므로 공식 비교에서 제외한다.

이번 비교의 텍스트 실험과 VLM 실험은 API 답변을 완전히 고정한 단일 변수 실험이 아니다. 따라서 전체 상승폭 3.04%p를 전부 VLM 효과라고 단정하지 않는다.

현재 값에는 `supplemental-set-b15`의 골든셋 오류가 포함되어 있다. 모델은 실제 정답 후보 15개를 반환했지만 실행에 사용한 골든셋에는 12개만 등록돼 있었다. 누락된 전북대학교 75일, 정읍시 80일, 파주 60일 문서가 오답으로 계산되면서 B15의 Precision이 80%, F1이 88.89%로 낮아졌다.

### B15 정답을 15개로 수정했을 때의 단순 재계산

다른 문항의 결과가 동일하다고 가정하면 다음처럼 바뀐다.

| 지표 | 현재 | B15 수정 가정 |
| --- | ---: | ---: |
| Macro Precision | 74.23% | **75.77%** |
| Macro Recall | 95.00% | **95.00%** |
| Macro F1 | 79.68% | **80.53%** |
| 완전 일치율 | 46.15% | **53.85%** |
| 정답 개수 일치율 | 61.54% | **69.23%** |

B15 수정만으로 전체 Precision 문제가 모두 해결되는 것은 아니다. `B4`, `B3`, `B1`, `B10` 등 다른 Set 문항에도 불필요한 문서 반환이 남아 있다. 따라서 검색 후처리 개선은 여전히 필요하다.

B15의 골든셋 수정은 원문 근거 확인과 팀 승인 후 공식 반영한다. 승인 전에는 현재 값과 수정 가정 값을 구분해 표기한다.

## 7. 0점 문항 검수

텍스트 전용 실험에서는 0점 문항이 9건이었고, 현재 VLM 통합 실행에서는 6건이었다.

| 문항 | 검수된 원인 |
| --- | --- |
| `supplemental-qa-g03` | 복수 마감 정보를 모두 답하지 못한 생성 문제 |
| `supplemental-qa-g04` | 목표 문서 검색 실패 후 기권 |
| `supplemental-qa-g13` | 목표 문서 검색 실패 후 기권 |
| `supplemental-qa-g22` | 모델은 비교 판단을 기권했으나 채점기가 `partial_answer`로 오분류 |
| `supplemental-qa-g25` | 다른 사업을 찾아야 하지만 기준 사업 자체를 반환 |
| `visual-pdf-table-003` | 정답 문서는 찾았지만 표의 구조와 항목을 답하지 못함 |

`g22`의 실제 답변은 사업예산 986,945,000원을 제시한 뒤 국내 시장 평균 정보가 없어 비교할 수 없다고 답했다. 질문의 최종 판단에는 정상적으로 기권했지만, 현행 채점기는 기권 문장 안의 숫자를 실질 답변으로 간주해 `partial_answer`로 분류했다. 따라서 이 문항은 생성 실패가 아니라 **채점기의 기권 판정 개선 대상**이다.

VLM 그림 문항에는 0점 사례가 남아 있지 않다. `visual-pdf-table-003`은 그림 VLM 경로가 아니라 구조화 텍스트로 처리한 표 문항이다.

## 8. 검색·생성·채점 문제 분리

### 검색 문제

- `g02`: 버스정보시스템 문서 대신 무관한 문서 검색
- `g04`, `g13`, `g21`, `g24`: `2025년 통합접수시스템 운영` 문서를 찾지 못함
- `g25`: “다른 사업”을 찾아야 하지만 기준 사업 자체를 반환

### 생성 문제

- `g03`: 두 종류의 접수 마감을 각각 답하지 않고 하나로 합침
- `g08`: 필수 사실 일부 누락
- `g12`: 일부만 답하고 부분 기권
- `g19`: 필수 사실 일부 누락
- `h16`: 정답 요소 일부 누락
- `visual-pdf-table-001`: 표 답변 일부만 맞아 50점
- `visual-pdf-table-003`: 정답 문서는 찾았지만 표 내용을 답하지 못해 0점

### 채점·측정 문제

- `g22`: 정상적인 근거 포함 기권을 `partial_answer`로 오분류
- `set-b15`: 정답 15개 중 12개만 골든셋에 등록
- `c19`: 최신 답변은 필수 사실 3/3을 충족해 100점이다. 이전 보고서의 “6개 중 1개 누락”은 `[재공고]`가 포함된 문서 ID를 중간에서 잘라낸 추출 정규식의 영향으로 보이며, 최신 생성 답변 실패가 아니다.

`c19`는 최신 실행에서 평택시 BIS와 인천공항 ERP의 기술 80%·가격 20%, 나머지 네 사업의 기술 90%·가격 10%, 비율 차이의 구체적 이유 미기재를 모두 포함했다. 따라서 최신 실행의 C19를 검색·생성 실패 사례로 분류하지 않는다.

## 9. 결론

현재 산출된 End-to-End 점수는 **85.37점**이지만, B15 골든셋 누락과 G22 기권 오분류가 포함된 수정 전 잠정값이다. 두 사항을 반영하면 점수가 상승할 가능성이 있으나, 정식 수정과 재채점 전에는 보정값을 공식 점수로 사용하지 않는다.

VLM 시각 근거가 연결된 그림 문항 4건은 모두 100점을 기록했다. 정확한 대상 이미지가 주어진 경우 VLM 판독 결과를 생성 파이프라인에 연결하는 방식이 효과적임을 확인했다.

다음 검증 순서는 다음과 같다.

1. B15 정답 문서 15개를 팀 승인 후 골든셋에 반영
2. G22와 같은 “근거를 설명한 뒤 최종 판단을 기권한 답변”을 정상 기권으로 처리하도록 채점기 보완
3. `[재공고]` 등 대괄호가 포함된 전체 문서 ID를 보존하는 수정 노트북으로 재실행
4. 수정 후 공식 지표와 문항별 결과를 다시 산출

## 10. 재현성 주의사항

- 이번 실행은 문항마다 VLM을 새로 호출한 것이 아니라 기존에 저장된 시각 판독 결과를 연결했다.
- 대상 이미지 선택에 Golden Set의 근거 참조값을 사용했으므로 완전한 블라인드 시각 검색 평가로 해석하지 않는다.
- 서로 다른 실행의 답변과 점수를 섞지 않도록 실행 ID, 생성 코드 커밋, 골든셋 해시, 채점기 버전을 함께 기록해야 한다.
