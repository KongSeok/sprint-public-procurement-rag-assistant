# 채점기 개선 보고서 v2 → v3.0.1

작성일: 2026-09-09

## v2에서 고친 것

- **실행 오류와 기권 분리**: `answered`, `partial_answer`, `abstained`, `empty_response`, `execution_error`의 5가지 상태로 구분한다. API 오류는 더 이상 기권으로 잡히지 않는다.
- **점수 이원화**: 정상 생성분만 보는 `conditional_score`와 오류·빈 응답까지 포함하는 실제 시스템 관점의 `end_to_end_score`를 분리한다.
- **부분 답변 정상 분류**: “예산 3억, 계약기간은 확인 불가” 같은 답변을 전체 기권이 아닌 `partial_answer`로 분류한다.
- **지표명 정정**: `compatible_overall_score`를 `lexical_fact_score`로 변경했다. 이는 종합 성능이 아닌 어휘 호환성 보조지표다.
- **Set 정보 누출 제거**: Set 문항 채점 시 정답 개수로 검색 대상 수를 미리 정하던 방식을 제거했다.

## v2의 잔여 문제와 v3.0.0의 개선 시도

- **기권 인식 누락**: “확인되지 않습니다” 같은 실제 기권 표현을 인식하지 못해 기권이 정답인 문항이 채점에서 빠지는 문제를 해결하기 위해 표현 목록을 확장했다.
- **조사·어미 차이**: “BIS와”와 “BIS”, “않음”과 “않습니다” 같은 차이를 완화하기 위해 Kiwi 형태소 분석기로 조사·어미를 제거한 뒤 비교하도록 수정했다.
- **숫자 표기 차이**: “100분의 10”과 “10%”, “20억”과 “20억원”을 제한적으로 동치 처리했다.

## v3.0.0 부작용과 v3.0.1 재수정

형태소가 40% 이상 겹치면 통과시키는 v3.0.0 방식은 과대 채점을 발생시켰다.

- `c18`: 마감일을 답하지 않았지만 “입찰”, “제출” 단어만 겹쳐 0점에서 100점으로 상승
- `g23`: 페이지 숫자를 답하지 않았지만 “본문”, “페이지” 단어만 겹쳐 0점에서 100점으로 상승

따라서 v3.0.0의 74.67점은 공식 비교에서 제외하고 v3.0.1에서 다음과 같이 보수적으로 수정했다.

- 필수 문구에 숫자가 있으면 답변에도 그 숫자가 있어야 통과
- 형태소는 40%가 아닌 **100% 일치**해야 인정
- v2가 인정하던 표현은 유지
- v3의 추가 구제 범위는 조사·어미와 검증된 숫자 표기 차이로 제한

## 채점기 문제가 아닌 사례

v3.0.1에서도 점수가 오르지 않은 다음 사례는 채점 로직이 아니라 검색 또는 답변 생성 단계의 문제다.

- **`c19` 66.67점**: 조사·어미 문제가 아니다. 평택시 BIS와 인천공항 ERP의 기술 80%·가격 20% 정보를 답변에서 찾지 못했다.
- **`g11` 0점**: 입찰 참여 가능 여부를 답하지 못하고 기권했다.
- **`g21` 0점**: 필요한 참가 조건과 실적평가 정보를 답하지 못했다.

이 사례들은 채점기를 더 느슨하게 만들어 해결할 문제가 아니다. 검색 또는 생성 단계에서 실제 정보를 가져오도록 개선해야 한다.

## 최종 판단

- v3.0.0은 과대 채점 때문에 사용하지 않는다.
- v3.0.1을 결정론적 어휘 기반 공식 채점기로 사용한다.
- `lexical_fact_score`는 의미 정확도를 보장하는 최종 종합점수가 아니라 보조지표다.
- 의미 정확도와 근거 충실도는 향후 사람 검수 또는 별도의 LLM Judge 평가로 보완한다.
