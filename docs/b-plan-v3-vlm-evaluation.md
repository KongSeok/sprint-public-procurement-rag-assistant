# B안 V3 선택적 VLM 통합 실험 보고서

## 1. 실험 목적

B안 V2의 텍스트 검색·생성 흐름을 유지하면서, 문서 속 그림에 답이 있는 질문에만 로컬 VLM을 사용해 시각 근거를 읽고 생성 모델에 전달했을 때의 효과를 확인했다.

이번 구현은 `feat/vlm-visual-retrieval` 브랜치의 이미지 추출·OCR·레이아웃·시각 청크 설계를 참고하되, 해당 브랜치는 수정하지 않고 `develop`에 별도 실험 모듈로 통합했다. 기존 Evidence-Harness 실험 트랙은 포함하지 않았다.

## 2. 실험 구성

- 평가 데이터: Golden Set V3의 시각 문항 10건
  - 표 문항: 6건
  - 그림 문항: 4건
- 문서 검색 및 최종 답변: B안 V2 흐름 유지
- 그림 문항 처리: 로컬 `Qwen/Qwen3-VL-8B-Instruct` 사용
- 표 문항 처리: 기존 구조화 텍스트 사용
- 최종 답변 생성: `gpt-5-mini`
- 외부 API 전달 범위: 질문, 검색된 문서 텍스트, 로컬 VLM이 전사한 시각 근거
- 외부 API에 원본 이미지는 전달하지 않음

### 시각 근거 연결 방식

- HWP 그림: 원본 객체의 SHA-256 해시로 Golden Set의 대상 객체와 정확히 일치하는지 확인
- PDF 그림: Golden Set의 대상 페이지와 바운딩 박스를 사용해 영역 이미지와 전체 페이지를 각각 판독
- 저장 정보: 근거 ID, 원본 문서 해시, 이미지 해시, 페이지, 바운딩 박스, 좌표계, 근거 연결 방식

이 연결은 현재 **정답 위치를 알고 있는 평가용 locator**이다. 따라서 생성 단계에서 시각 정보를 활용할 수 있는지는 검증하지만, 사용자의 질문만으로 올바른 그림을 찾아내는 end-to-end 시각 검색 성능을 뜻하지는 않는다.

## 3. 실행 환경

- 인프라: GCP Compute Engine
- GPU: NVIDIA L4, VRAM 약 23 GB
- OS: Ubuntu Accelerator 24.04 계열
- GPU 드라이버: 580.173.02
- 드라이버 표시 CUDA: 13.0
- VLM 실행기: vLLM 0.28.0
- PyTorch: 2.13.0+cu130
- VLM: `Qwen/Qwen3-VL-8B-Instruct`
- VLM 정밀도: BF16
- 모델 적재 메모리: 약 16.33 GiB
- 최대 문맥 길이: 4,096 tokens
- GPU 메모리 사용률 설정: 0.90
- 환경 제약: 서버에 `nvcc`가 없어 FlashInfer sampler를 비활성화하고 실행

## 5. B안 V2와 비교

B안 V2의 동일한 시각 10문항 점수는 4회에 걸쳐 `47.00`, `52.00`, `49.00`, `49.00`점이었고 평균은 `49.25점`이었다. 이번 B안 V3는 `88.33점`으로, V2 네 번의 평균보다 **39.08%p 높았다**.

다만 V3는 현재 한 번만 실행한 결과이므로, 이 차이를 재현 가능한 최종 개선폭으로 확정할 수는 없다. 같은 조건의 반복 실험이 추가로 필요하다.

또한 문서 검색 Recall `0.80`과 검색 컨텍스트 사실 포함률 `0.54`는 V2와 동일하다. 즉 이번 상승은 검색기가 더 정확해져서가 아니라, 대상 그림을 지정해 VLM으로 읽은 뒤 생성 모델에 시각 근거를 보강한 효과로 해석해야 한다.

## 6. 확인된 성과

- 그림 4건 모두에서 VLM 전사가 성공했고 필수 사실을 모두 포함했다.
- HWP의 원본 그림 객체와 평가 대상 객체를 해시로 검증해 잘못된 이미지를 연결할 위험을 줄였다.
- PDF는 잘린 영역과 전체 페이지를 독립적으로 판독해 주변 문맥과 세부 글자를 함께 확보했다.
- 시각 근거의 출처를 기계가 읽을 수 있는 형태로 결과 CSV와 manifest에 보존했다.
- 원본 이미지를 외부 생성 API로 보내지 않고 로컬 GPU에서 처리했다.

## 7. 한계와 해석 주의사항

1. **시각 검색 자체는 아직 미완성이다.** Golden Set에 기록된 대상 페이지·객체를 이용했으므로, 실제 질의에서 적절한 그림을 자동 탐색하는 단계는 검증하지 않았다.
2. **검색 병목은 그대로다.** 문서 검색 Recall과 컨텍스트 사실 포함률은 개선되지 않았다.
3. **인용 출력 연결이 미완성이다.** 내부 결과에는 근거 ID와 좌표가 보존되지만, 최종 답변이 평가기가 요구하는 `[근거: ...]` 형식을 충족하지 않아 인용 점수는 0이다.
4. **표 문항은 VLM을 사용하지 않았다.** 표 구조를 이미지로 읽는 방식과 기존 구조화 텍스트 방식의 비교가 필요하다.
5. **평가셋이 확정본이 아니다.** Golden Set V3 항목은 현재 draft 상태이며 일부 항목은 `enabled=False`로 표시돼 있다.
6. **V3 반복 검증 전이다.** 단일 실행 결과이므로 변동성과 재현성은 아직 확인되지 않았다.
