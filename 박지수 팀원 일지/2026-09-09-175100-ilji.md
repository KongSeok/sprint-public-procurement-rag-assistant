## 현재 프로젝트 위치

1. 데이터 전처리·refined 98 source-of-truth·page baseline과 EvidenceStore/검색 기반은 구현되어 있다.
2. 골든셋은 131개 기록과 parser 2개 회귀가 있으나, 공식 qrel 승인·sealed held-out·paired 비교 계약이 모두 닫힌 상태는 아니다.
3. 검색 실험은 recorder와 지표 구현까지 왔고, 동일 frozen 입력을 봉인한 뒤 3종 검색을 비교해야 한다.
4. 생성 쪽은 Qwen8B 전체 실행에서 오류 86개를 확인했고, 일부 4개 형식 수리만 끝났다. 현재 HOTLINE.2는 실제 생성 품질을 측정한 단계가 아니다.
5. UI와 전문 경로는 구현·검수 선행 조건이 남아 있어 기본 Streamlit을 새 hotline 결과로 바꾸지 않았다.
6. 따라서 전체 대비 위치는 “기반 구현 완료 → 실행 계약·검색 비교 준비 → 생성 오류 수리와 실제 평가 대기”다. 제품 완료나 성능 우승 단계는 아니다.

- GitHub 인덱스는 같은 일지 링크를 유지하고, 이번 보강본을 원격 readback으로 확인한 뒤 commit/push한다.
- Discord는 이미 같은 일지 링크가 전송된 상태이므로 중복 메시지를 만들지 않는다. 예약 실행은 기존 프로토콜에 따라 남은 실행일에도 게시 후 같은 채널 알림을 시도한다.
